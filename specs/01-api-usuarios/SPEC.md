# FEATURE: CRUD de Usuários

## OBJETIVO
Criar uma Web API simples para gestão de utentes (Create, Read, Update, Delete) que servirá como base de estudos para Clean Architecture e SOLID. 

## REQUISITOS DE NEGÓCIO
- O sistema deve permitir criar um utilizador com Nome e Email.
- O sistema deve permitir listar todos os utilizadores.
- O sistema deve permitir buscar um utilizador pelo seu ID (Guid).
- O sistema deve permitir atualizar o Nome e Email do utilizador.
- O sistema deve permitir eliminar um utilizador.

## RESTRIÇÕES
- Não haverá sistema de autenticação ou autorização (sem JWT) nesta fase.
- A entidade deve ser anémica ou extremamente simples (apenas validações básicas de null/empty).
